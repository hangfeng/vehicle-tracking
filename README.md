# 🚗 Vehicle Tracking System（出入管理系统）

企业级车辆出入管理系统，支持多角色权限控制、车牌识别、出入记录管理、报警与报表分析。

---

## 🧠 项目简介

本系统用于企业/园区的车辆出入管理，核心功能包括：

- 🚪 出入管理（车牌记录、时间、通道）
- 👥 多级权限控制（system_admin / group_admin / factory_manager / operator）
- 📊 报表与数据分析
- 🚨 异常报警
- 🤖 车牌识别（OCR / 门禁系统对接）
- 🧾 审计与日志


- Enterprise Vehicle Access Management System, support multi-role access control, license plate recognition, access record management, alarm and report analysis.

---

# # introduction

This system is used for vehicle access management in Enterprise/Park. The core functions include:

- access management (license plate record, time, channel)

- multi-level access control (System/group/factory/operator)

- reporting and data analysis

- abnormal alarm

- license plate recognition (OCR/access control system docking)

- audit and log
